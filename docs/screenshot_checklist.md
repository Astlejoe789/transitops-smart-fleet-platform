# TransitOps Screenshot Checklist

**Recommendation**: Set your browser resolution to `1920x1080` (Standard Full HD) for consistency. Use a tool like CleanShot X or standard OS screenshot tools. Capture both Light and Dark mode where appropriate.

## Core Flow (Required)
- [ ] 1. **Landing Page**: The marketing/splash screen (if applicable).
- [ ] 2. **Login**: The authentication portal.
- [ ] 3. **Dashboard**: The main KPI screen, showing revenue/expense charts and active trips. (Take one in Dark Mode, one in Light Mode).
- [ ] 4. **Fleet**: The vehicle data table.
- [ ] 5. **Vehicle Details**: A specific vehicle's profile showing specs and documents.
- [ ] 6. **Drivers**: The driver data table.
- [ ] 7. **Driver Details**: A specific driver's profile showing licenses and medical certs.
- [ ] 8. **Trips**: The list of all trips.
- [ ] 9. **Dispatch**: The active dispatch board / trip creation screen.
- [ ] 10. **Maintenance**: Preventive maintenance schedule table.
- [ ] 11. **Fuel**: Fuel logs.
- [ ] 12. **Expenses**: Operational expenses table.
- [ ] 13. **Customers**: The client CRM table.
- [ ] 14. **Vendors**: The vendor CRM table.
- [ ] 15. **Billing**: Invoicing overview.
- [ ] 16. **Reports**: Reporting module overview.
- [ ] 17. **Analytics**: The detailed BI analytics page.
- [ ] 18. **Settings**: User settings and profile.
- [ ] 19. **Administration**: System config or audit logs.
- [ ] 20. **Dark Mode**: Explicit toggle showcase.
- [ ] 21. **Mobile View**: Open Chrome DevTools, set to iPhone 14 Pro, and capture the Dashboard.
