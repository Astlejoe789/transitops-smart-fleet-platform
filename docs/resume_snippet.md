## Projects

**TransitOps | Full-Stack Smart Fleet Platform** 
*React, TypeScript, Node.js, Express, Prisma, PostgreSQL, Tailwind CSS* 
* [Live Demo](#) | [GitHub Repository](#)
* **Architected and developed** an enterprise-grade fleet management SPA that unified dispatching, vehicle maintenance tracking, driver credentials, and invoicing into a centralized dashboard.
* **Engineered a scalable backend** utilizing a modular monolith pattern (Controller-Service-Repository) in Express, strictly validating 40+ REST API endpoints with Zod and Prisma ORM.
* **Optimized frontend performance** by implementing advanced Vite chunking strategies (separating React, UI tokens, and React Query), completely eliminating >500kb bundle warnings and reducing initial load time.
* **Designed a premium UI/UX** utilizing Tailwind CSS v4 and Shadcn UI, featuring real-time KPI charting, infinite table pagination, and a global Light/Dark mode implementation.
* **Automated CI/CD deployments** by configuring custom `vercel.json` and `railway.json` pipelines, successfully hosting the decoupled frontend and database-backed API.
